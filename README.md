# 🛡️ AI Phishing Detection System

A FastAPI-based defensive cybersecurity tool that analyzes URLs and detects common phishing indicators.

## 📌 About

This project is designed to help identify potentially suspicious URLs by analyzing common phishing indicators and generating a risk score.

## ✨ Features

- 🔍 URL analysis
- 🛡️ Phishing risk detection
- 📊 Risk score out of 100
- ⚠️ Suspicious URL indicators
- 🌐 Simple web interface
- 🚀 FastAPI backend
- 📖 Interactive API documentation with Swagger UI

## 🛠️ Technologies

- Python
- FastAPI
- Uvicorn
- HTML/CSS
- REST API

## ▶️ How to Run

Clone the repository:

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
cd AI-Phishing-Detection-System
Create and activate the virtual environment:

python -m venv venv

Install dependencies:

pip install -r requirements.txt

Run the application:

python -m uvicorn app.main:app --reload

Open in your browser:

http://127.0.0.1:8000
📚 API Documentation

FastAPI Swagger documentation:

http://127.0.0.1:8000/docs
